Публикации
для сообществ.

Интеграция предназначена для администраторов, которые хотят планировать записи в своих сообществах.

Сейчас подключение сообщества работает по ключу доступа и поддерживает текст и ссылки. Упрощённое подключение через авторизацию ВК находится в подготовке и ожидает расширенных доступов.
